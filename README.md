# Monorepo Project

This workspace is set up as a pnpm monorepo with two app slots under `apps/` and shared packages under `packages/`

## Structure

- `apps/system-a` - application slot A
- `apps/system-b` - application slot B
- `packages/` - shared workspace packages
- `public/` - static assets
- `.vscode/` - editor configuration and tasks

## Scripts

- `pnpm dev`
- `pnpm build`
- `pnpm lint`
- `pnpm check`
